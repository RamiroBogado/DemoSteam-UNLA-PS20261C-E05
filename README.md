# DemoSteam UNLA PS 2026 1C - E05

MVP frontend inspirado en Steam, desarrollado con React + Vite como parte del proyecto académico de la materia Proyecto de Software.

---

# Descripción

DemoSteam es una aplicación web tipo plataforma de videojuegos que simula funcionalidades básicas de Steam mediante una SPA desarrollada con React.

El proyecto implementa un MVP funcional orientado a:
- navegación entre vistas
- autenticación simulada
- biblioteca de videojuegos
- instalación y ejecución de juegos
- sistema de amigos
- notificaciones
- persistencia local

---

# Tecnologías utilizadas

- React
- Vite
- React Router DOM
- JavaScript
- CSS3
- LocalStorage

---

# Features implementadas

## Primera etapa

### Catálogo de videojuegos
- Visualización de juegos disponibles
- Cards dinámicas
- Hero principal
- Buscador visual

### Detalle de videojuego
- Vista individual por videojuego
- Precio
- Descripción
- Acceso a compra

### Compra de videojuegos
- Checkout simulado
- Confirmación de compra
- Agregado automático a biblioteca

### Biblioteca de juegos
- Visualización de juegos comprados
- Estado de instalación

### Descargar e instalar videojuegos
- Simulación de instalación
- Estados:
  - Comprado
  - Instalando
  - Instalado

### Ejecutar videojuegos instalados
- Simulación de ejecución de juegos

---

## Segunda etapa

### Iniciar sesión
- Login simulado
- Navbar dinámica

### Registro de usuarios
- Formulario de registro
- Validación de contraseñas

### Recuperar contraseña
- Recuperación simulada vía email

### Sistema de amigos
- Búsqueda de usuarios
- Agregado de amigos

### Notificaciones
- Dropdown de notificaciones
- Badge con contador

# Instalación y ejecución

## Clonar repositorio

```bash
git clone https://github.com/RamiroBogado/DemoSteam-UNLA-PS20261C-E05.git
```

## Ingresar al proyecto

```bash
cd steam-mvp
```

## Instalar dependencias

```bash
npm install
```

## Ejecutar proyecto

```bash
npm run dev
```
