# DemoSteam UNLA PS 2026 1C - E05

MVP frontend inspirado en Steam, desarrollado con React + Vite.

## Features

- Ver catálogo de videojuegos
- Ver detalle de un videojuego
- Realizar compra de videojuegos
- Acceder a biblioteca de juegos
- Descargar e instalar videojuegos
- Ejecutar videojuegos instalados
